# Daily video pipeline (AI/ML/DL concept story videos)

**BRAND (user decision): the YouTube channel and Instagram page are called "Learn AI by Story".** Use it everywhere: the in-video series label (the `#series` text in gen.mjs, currently "AI · ML · DL STORIES") becomes "LEARN AI BY STORY"; every LinkedIn post and Reels/Shorts caption ends with a short line "Learn AI by Story: one concept, one story, every day" and the hashtag #LearnAIbyStory; study notes docs carry the line "Learn AI by Story" under the title.

**LENGTH RULE (user requirement): every video must be MORE THAN ONE MINUTE (target 65-90 s). Explain the concept properly: 7-9 scenes, about 170-230 narration words in total (Kokoro af_heart at 1.03 runs ~2.7 words/s), with a worked example, a common mistake or where it is used. After the build, verify each MP4 duration with ffprobe is >= 62 s; if shorter, add scenes/narration and rebuild. The earlier short videos are discarded; every ID is made fresh in order.**

Goal: 5 new vertical (1080x1920) English story videos per day, one character per concept, narration + captions, plus LinkedIn text posts and Reels/Shorts captions. Concepts come from the Roadmap doc (https://claude.ai/artifact/KhbB3q3ge5bb6NdAmEoGjQ, 510 concepts, modules M0-M22). Progress is tracked in project doc `claude/progress.md` (strict ID order from 0.01; earlier short videos are discarded).

**STUDY NOTES RULE (user requirement): for every concept, also write a study-notes document ("notebook") that explains the concept for students and new learners, to go with the LinkedIn post.** NOT a Jupyter notebook. One Docs doc per concept (create with the Docs tools, title `<id> <concept>: study notes`), plain-language and beginner friendly, about 1-2 pages: (1) the idea in one sentence; (2) the story from the video in 3-4 lines; (3) step-by-step explanation in simple words, defining every term; (4) a small worked example with numbers; (5) a simple diagram or table where it helps; (6) common mistakes and myths; (7) where it is used in real life; (8) 5 quick self-check questions with answers; (9) key takeaways and what to learn next (link to the next roadmap ID). No code walls; short code snippet only if it truly helps. Open each doc with the Artifact open action and list the 5 doc links in the final message. The LinkedIn text post for each video mentions the notes ("Full study notes: link in comments").

**THUMBNAILS AND TITLES RULE (user requirement): for every video create a YouTube thumbnail, an Instagram Reels cover, a YouTube title and an Instagram title.** Fetch `claude/brandkit.py` with project_read, write items.json (`[{"id":"0.06","title":"<short 2-5 word title>","hook":"<short hook line>"}]`) and run `python3 brandkit.py thumbs items.json thumbs` (needs python playwright with chromium; it outputs `<id>-yt-thumb-1280x720.png` and `<id>-reel-cover-1080x1920.png`). Look at the images and fix text that overflows. Deliver the PNGs with SendUserFile. In the posting kit doc, per video give: YouTube title (under 70 characters, curiosity + keyword, e.g. "What is AI? Narrow vs General Intelligence (Simple Story)"), YouTube description (2-3 lines, concept summary, study notes link placeholder, the BRAND line, 5 hashtags, #Shorts), Instagram title/first-line hook, Instagram caption and hashtags. The channel banner and profile pictures already exist (one-time): do not recreate them.

## Daily steps
1. Read `claude/progress.md`, pick the next 5 concepts in roadmap ID order.
2. Edit gen.mjs: replace the `const STORIES = [ ... ];` array (inside part B) with 5 new episode specs. Each: `{ id: "ep-<n>-<slug>", key: "e<code>", n: <unique int>, tag: "<MODULE> · <n>", scenes: [scene builders], en: ["narration per scene"] }`. Scene count must equal narration lines. 7-9 scenes, 20-30 words each, a story character who explains the concept (hook first line, one-line takeaway last). Scene builders available: sChars, sCards, sBars, sPlot, sSegments, sFlow, sCompare, sNest, sVectors, sEq, sContour, sTargets, sTimeline (see the code for options); write new builders for new visuals, using the same layout rules.
3. `MODE=scripts node gen.mjs` writes scripts.json; generate Kokoro wavs to en_story/<key>_s<i>.wav (`Kokoro(...).create(line, voice="af_heart", speed=1.03, lang="en-us")`, `soundfile.write`). Run in background, ~2 min.
4. `LANG_MODE=en node gen.mjs` builds ep-*-en projects. Run `npx hyperframes check --json` in each (cd into the dir); fix layout errors (content_overlap etc.).
5. Snapshot each scene (`npx hyperframes snapshot --at t1,t2,... --no-end -o snaps`, take ~85% into each scene), build a contact sheet of crops (0,168,1080,1340), look at it, fix problems, rebuild.
6. Render in background: `cd <dir> && npx hyperframes render -o ../final/<id>-en.mp4` (~4 min each, run sequentially in a background script; foreground sleep is blocked, wait with `timeout 110 tail -f /dev/null`).
7. Write the study notes docs (STUDY NOTES RULE), make thumbnails/covers (THUMBNAILS AND TITLES RULE), then deliver all MP4s and PNGs with SendUserFile; write the posting kit as a Docs doc (LinkedIn text post + YouTube title/description + Instagram title/caption/hashtags per video, with the BRAND line), open it with the Artifact open action; update `claude/progress.md`.

## Layout rules
Nothing in the top 168 px; content y 168-1330; captions at y ~1130-1310 (auto); heading at y 250 (74px); visuals in y 460-1100; text >= 28px; palette bg #0A0F1F, panel #131A33, cyan #22D3EE, amber #FBBF24, pink #FB7185, green #34D399, violet #A78BFA. Don't put CSS transform on GSAP-animated elements. No repeat:-1. Never loop ElevenLabs (rate limited, not needed).
