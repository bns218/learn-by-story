# Posting kit

One document per batch: **Posting kit: batch N** (Claude Docs doc if available — open it — else
`out/batch-N/posting-kit.md`). One section per video, in batch order:

| Piece | Rules |
| --- | --- |
| LinkedIn post | 120–220 words; hook line, the story in 2–3 lines, the takeaway, best 2–3 source links from the research log, brand line |
| YouTube title | ≤ 70 chars, concept name in plain words, curiosity without clickbait |
| YouTube description | 2–3 sentence summary, "Free study notes: link in bio", best 2–3 source links, chapter-free, brand line |
| Instagram title | ≤ 40 chars, fits on the Reels cover |
| Instagram caption | 60–120 words, story hook first, takeaway, "study notes in bio", brand line |
| Hashtags | 10–15, mix of broad (#machinelearning #ai) and concept-specific |

Every piece carries the brand line "Learn AI by Story". Only claims backed by the research log.
